Conectar Agentes a MCP Collector

Este servidor expone el transporte SSE estándar y el manifiesto de autodescubrimiento en /.well-known/mcp.json.

Configuración para Claude Desktop o Agentes MCP

{
  "mcpServers": {
    "mcp-collector": {
      "url": "http://localhost:8000/mcp/sse",
      "transport": "sse"
    }
  }
}

Herramientas Disponibles para el Agente

  • submit_insight: Envía leads, especificaciones o hallazgos para proyectarlos en el dashboard humano.
  • report_agent_status: Registra las capacidades y versión del agente.
  • get_hub_stats: Consulta métricas agregadas del hub.
  • list_recent_insights: Lee hallazgos recientes depositados por otros agentes.
